# 開工

目的：讓使用者在**任何一台電腦**坐下來，30 秒內知道上次做到哪、現在該做什麼。

## 步驟

### 1. 確認在哪個專案

看目前工作目錄有沒有 `AGENTS.md`。

- **有** → 就是這個專案，繼續
- **沒有** → 往上一層找；再找不到就問使用者要開哪個專案（可列出 `07專案開發\` 底下的資料夾給他選）

### 2. 讀兩份檔案

- `AGENTS.md` → 專案目的、時程、對照表
- `handoff.md` → 上次做到哪、下一步、卡關

**只讀這兩份，不要一開場就掃整個資料夾**，那會吃掉大量 context 又幫不上忙。

### 3. 檢查同步狀態

- 比對 `handoff.md` 的「最後更新」機器名稱與目前這台（執行 `hostname` 取得）
- **不同台** → 明確告訴使用者「上次是在 <某台> 做的」，並提醒確認 Google Drive 已同步完成（看檔案總管的同步圖示）
- 同一台 → 不用特別提

### 4. 看時程有沒有逼近

對照 `AGENTS.md` 的時程表與今天日期，有**7 天內到期**且未完成的節點就主動提出來。

### 5. 回報

用這個格式，簡短：

```
專案：<名稱>
上次：<某台電腦>，<日期>
做到：<一兩句>
下一步：
  1. <動作>
  2. <動作>
卡關：<有就寫，沒有就省略這行>
時程提醒：<7 天內到期的節點，沒有就省略>
```

回報完**停下來等指示**，不要自動開始做下一步。

## 不要做的事

- 不要跑 `git status` 或任何 git 指令（這套流程不用 git）
- 不要自動改任何檔案
- 找不到 `handoff.md` 時不要自己編一份，改問使用者要不要跑 `project-init`
